## 🧩 Featured Projects

### StudentSync (Web)
A multi-college event platform where students discover, register for and check in to events, organizers run them, and admins oversee everything.
- Race-safe seat booking and an automated waitlist, verified with 50-way concurrent registration tests
- Crash-safe background worker for reminders, waitlist offers and alerts (email, in-app and mobile push) with retries and no duplicates
- Real-time chat with Socket.IO and Redis, role-based access, signed QR tickets, rate limiting and an admin audit log
- **Stack:** Next.js, TypeScript, Tailwind CSS, Redux, REST APIs, Better Auth, MongoDB

### StudentSync (Mobile)
A React Native app on top of the same backend, with no backend changes.
- Event browsing, registration, QR tickets, bookmarks, reviews and personal analytics
- Session-cookie auth kept in encrypted device storage, role-based screen gating, per-event real-time chat, local reminders and add-to-calendar
- Redux Toolkit with RTK Query, react-hook-form with Zod, NativeWind light and dark themes, Reanimated animations, Jest tests
- **Stack:** React Native, Expo, TypeScript, NativeWind, Redux Toolkit, RTK Query, Socket.IO, Zod
